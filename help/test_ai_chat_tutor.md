## Как протестировать вручную (через Supabase)

### Вариант 1: Через Supabase Dashboard

1. Открой **Supabase Dashboard** → Functions
2. Найди `ai-chat-tutor`
3. Нажми **Invoke**
4. Вставь JSON:

```json
{
  "messages": [{"role": "user", "content": "Как решить уравнение x+5=10?"}],
  "diagnosticProfile": {"math_level": 2, "learning_style": "balanced"},
  "weakTopics": ["linear_equations"],
  "context": {},
  "language": "ru"
}
```

5. Нажми **Send**
6. Проверь ответ — должен быть Метод Сократа (наводящие вопросы)

## 🚨 Частые проблемы и решения

### Проблема 1: Ошибка 500 (Internal Server Error)

**Причина:** Переменная не определена в промпте

**Решение:** Проверь, что все переменные имеют дефолты:
```typescript
const mathLevel = diagnosticProfile?.math_level || 1; // ✅ ПРАВИЛЬНО
const mathLevel = diagnosticProfile.math_level;        // ❌ ОШИБКА если null
```

**Статус:** ✅ Исправлено в коде

---

### Проблема 2: ИИ пишет слишком длинные ответы

**Причина:** Нет ограничения на длину

**Решение:** Добавь в промпт (строка ~90):

```typescript
### ДОПОЛНИТЕЛЬНЫЕ ПРИНЦИПЫ
...
5. Держи ответы краткими, но полными
6. Ограничивай ответы до 3-4 абзацев максимум  // ← ДОБАВИТЬ ЭТО
7. Используй эмодзи умеренно
```

**Статус:** ⏳ Можно добавить, если будет проблема

---

### Проблема 3: ИИ НЕ использует Метод Сократа

**Причина:** Промпт не достаточно жесткий

**Решение:** Усилить инструкцию в промпте (строка ~69):

```typescript
3. **Метод Сократа (КРИТИЧНО!):** 
   НЕ ДАВАЙ правильный ответ сразу! 
   Всегда начинай с вопроса к студенту:
   - "Что ты думаешь, какой первый шаг?"
   - "Какое число здесь мешает нам найти x?"
   - "Что происходит с числом при переносе через равенство?"
```

**Статус:** ✅ Уже есть в промпте, но можно усилить если нужно
